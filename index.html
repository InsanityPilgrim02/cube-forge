Cube Forge

Settings

What this is

Cube Forge builds legal cube draft packs from a CSV, a Cube Cobra list or a saved JSON file. Pack building runs on your device; only Cube Cobra import and image preload need a connection. It's an unofficial fan tool and isn't affiliated with Wizards of the Coast, Cube Cobra or Scryfall.

Getting started

  • Cube Cobra: paste a cube list link or ID into the box at the top and press Import. You need a connection to import.
  • CSV or JSON: leave the box empty and press Import to pick a file, or drop one anywhere on the page. A CSV needs Name and Rarity columns. Quantity, colour, set, collector number, mana cost, CMC and type line are optional. Colours are worked out from the mana cost when there is no colour column.
  • Quantities: if the cube has no quantity column, set how many copies of each common, uncommon and rare/mythic you own under Cube quantities and press Apply.

Pack configuration

  • Set the number of packs and how many non-land commons, uncommons and rares/mythics each pack gets, then press Generate packs.
  • Seed: the same seed, cube and settings give the same deal. A blank or auto-filled seed is re-rolled on every Generate; type your own, or press New random seed, to pin it.

Pack rules

  • Exact non-land common, uncommon and rare/mythic counts, plus one land slot.
  • Land slot: 33% chance of a cube common land (if any remain), otherwise a random basic.
  • At least 2 mono-colour cards of each colour. Multicolour, colourless and basics don't count toward the minimums.
  • No duplicate card names in a pack, and cube quantities are never exceeded.
  • Invalid deals are re-rolled up to 100 times. Repairs can swap in unused leftover cards. If every attempt fails, Deal info lists the reasons and how often they happened, which points at thin colours or too many packs for the pool.

Packs and leftovers

  • Sorting: cards are ordered by rarity, then colour, then mana value. Common lands and basics sit at the bottom.
  • Leftover pool: every cube card not used in a pack. Generated basics aren't counted. Tap the C / U / R/M and colour tiles to filter the list; the colour totals follow the rarities you have selected.

Card images

  • Preview: hover a card name, or tap it on a touch screen, to see its image when it is saved on this device.
  • Preload card images: downloads from Scryfall (set and collector number when available, plus that set's five basics) and keeps them in the browser. Clear saved card images removes them. Only Preload uses the network.

Saving and exporting

  • Export ▾: copy the packs as text, download a CSV, print (3×3 packs per page), or download JSON.
  • JSON saves everything: the cube, quantities, settings, seed, generated packs and the cached images for that cube. Import it again to pick up where you left off. Files with images can be large.

Tips

  • CSV colour tags can be wrong. Cube Cobra import, or a reliable mana cost column, gives better results.
  • Land detection needs a type line, which Cube Cobra provides automatically.

Settings

  • Data: deletes everything Cube Forge has saved on this device. Cubes and packs are never stored automatically, so use Export ▾ → JSON to keep them.
  • Look for updates: only checks when you press it. If a newer version is on the server the button turns green and reads Update now. The installed app runs from its offline copy and never checks by itself; a normal browser tab checks once when it opens and downloads any newer copy for the next reload.

Delete all data

Removes everything Cube Forge has saved on this device: cached card images and the image lookup list. This can't be undone. You'll be asked to confirm first.

Your loaded cube, settings and packs live only in this tab and aren't saved on the device. Export a JSON file first if you want to keep them.
