MTG Cube Draft Pack Generator

Upload your Cube, set pack composition, and generate draft packs that respect normal draft pack rules.

About this app

Generate legal cube draft packs from a CSV or Cube Cobra list. Pack building stays on your device; only optional image preload and Cube Cobra import need the network.

1. Load Cube

  • Option A — CSV: Browse or drop a CSV with at least Name and Rarity. Optional columns: quantity, colour, set, collector number, mana cost, type line.
  • Option B — Cube Cobra: Paste a cube list URL or ID. Loads official card data (mana costs, set, types) over the network once; packs still generate offline afterward.
  • If the CSV has no quantity column, set copies per rarity under “Cube Quantities” and apply.

2. Card images

  • Hover or tap a card name to show its image when one is already cached on this device.
  • Preload card images downloads from Scryfall (set + collector number when available, plus that set’s five basic lands) and stores them in the browser cache.
  • Clear saved card images removes that cache. Preload uses the network; normal browsing does not.

3. Pack configuration

  • Set number of packs and how many non-land commons, uncommons, and rares/mythics each pack should contain.
  • Optional seed: same seed + same cube + same settings reproduces the same deal. Leave blank for a random seed, or use “New random seed”.

4. Pack rules (every pack)

  • Exact non-land common / uncommon / rare counts as configured.
  • One land slot: 33% chance of a cube common land (if any remain), otherwise a random basic (Plains, Island, Swamp, Mountain, Forest).
  • At least 2 mono-colour cards of each colour (W, U, B, R, G). Multicolour, colourless, and basics do not count toward those minimums.
  • No duplicate card names in a pack.
  • Cube quantities are never exceeded. Invalid deals are re-rolled (up to 100 attempts).

5. Pool report & deal info

  • On success: a short summary of the pack rules used.
  • On failure: aggregated reasons (e.g. which mono-colour minimums were short, and how often). Use that to find cube makeup issues — thin mono colours, too many packs for the pool, awkward land density, and similar. Colour repair order rotates each attempt so those tallies are less biased toward one colour.

6. Leftover pool

  • Cube cards not put into any pack. Generated basics are not part of the leftover cube list.
  • Tap the C / U / R/M and colour tiles to filter the list (blue = included). Colour totals update from the selected rarities.

7. Generated packs

  • Cards sorted by rarity, then colour, then mana value. Common lands and basics sit at the bottom; uncommon/rare lands stay with their rarity.
  • Copy All as Text, Download CSV, or Print (3×3 packs per page).

Tips

  • CSV colour tags can be wrong — prefer Cube Cobra import or a reliable Mana Cost / type column when possible.
  • For land detection, the list needs a type line (Cube Cobra provides this automatically).
